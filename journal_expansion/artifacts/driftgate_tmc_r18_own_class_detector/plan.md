# Round 18 실행 계획

지시문 0.2의 6번에 따라 run당 시간을 재고 전체 계획을 적습니다. 예산은 RTX 4090 4대(GPU 0–3), 벽시계 7일입니다. 시간은 실제 run에서 다시 재고 이 문서를 고칩니다.

## 1. 시험 실행에서 잰 시간 (2026-11-20, GPU 한 대에 run 하나)

| 구성 | 학습 1라운드 | 판별기 학습 1라운드 | 비고 |
|---|---|---|---|
| `pretrained-finetuned-block` (CIFAR-10, S1) | 약 34초 | 약 8.5초 | 2라운드 시험, GPU 메모리 약 3.9 GB |
| `cnn-scratch` (CIFAR-10, S1) | 약 12초 | 약 8.6초 | 2라운드 시험 |
| `pretrained-frozen-block` (CIFAR-100, S1) | 약 33초 | 약 10초 | 2라운드 시험(매 라운드 평가 포함) |

- 실제 run은 5라운드마다 평가하므로 평가 시간은 시험보다 작습니다. GPU 한 대에서 run 4–5개를 함께 돌리면 run마다 1.5–2.5배 느려질 것으로 봅니다.
- 추정: 300라운드 학습 run 하나는 MobileNetV2에서 약 4–9시간, CNN에서 약 2–4시간입니다. 재생 run(150라운드, 평가만)은 약 10–20분입니다.

## 2. 단계별 run

| 단계 | run | 학습 run 수 | 재생 run 수 |
|---|---|---|---|
| 2단계, 개발용 | 구성 3개 × S1 seed 8–10 | 9 | 9 |
| 2단계, 평가용 | 구성 3개 × (S1 seed 0–2, S2 seed 0–2), 사전학습 구성 2개 × CIFAR-100 seed 0–2 | 24 | 24 |
| 3단계 (조건부) | 7.3절의 판정에 따라 정합니다. | 미정 | 미정 |

- 2단계 개발용 run이 끝나면 3.5절의 선택을 하고 commit한 뒤 평가용 run을 넣습니다(`scripts/r18oc_jobs.py eval`). 평가용 run에는 고른 조합의 `frozen-at-home`, `every-10` 판도 기록합니다.
- 추정 벽시계: 개발용 약 0.5일, 평가용 약 1일입니다. 2단계는 약 1.5–2일 안에 끝날 것으로 봅니다.

## 3. 디스크

- 남은 디스크는 약 150 GB입니다. 300라운드 run 하나의 요청 기록은 CIFAR-10에서 약 0.5–1 GB, CIFAR-100에서 약 2–3 GB로 추정합니다. 라운드 150 checkpoint는 MobileNetV2에서 약 100 MB입니다.
- 2단계 전체는 약 40 GB로 추정합니다. 3단계 전에 다시 계산합니다.

## 4. 예산이 모자랄 때 (지시문 6.3의 6번)

500대 → held-out 비율 ablation → `cnn-scratch`의 CIFAR-100 → S1-fast → 5개 seed를 3개로, 순서로 줄이고 `decisions.md`에 적습니다.
