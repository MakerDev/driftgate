**★ Decisive stat = detrended corr(ρ, signal). Quadratic detrend is INVALID** — ρ(round) is itself an inverted-U hump (corr with -(r-75.5)²=+0.86), so a quadratic absorbs the drift response (collapses disagree 0.72→0.26, flips entropy sign). Use **isotonic (monotone-decreasing) detrend** — convergence is monotone, drift is a hump, cleanly separable: **entropy resid corr(ρ)=+0.08 (≈0, no drift response, trend R²=0.997); disagreement resid corr(ρ)=+0.50 (tracks drift, trend R²=0.94).** Raw corr for reference: entropy −0.09, disagree +0.52.
